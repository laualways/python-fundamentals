# Python Fundamentals & Problem Solving

A curated collection of core Python exercises, algorithmic mini-projects, and practice scripts developed during the 100 Days of Code curriculum. The repository focuses on building rock-solid foundations in procedural logic, data structures, state handling, object-oriented programming (OOP), and clean coding standards (PEP 8).

## 🛠️ Concepts & Highlights

* **Control Flow & State Machines:** Interactive terminal loops, nested while structures, and conditional branching without memory leaks.
* **Data Structures:** Dictionaries as first-class function dispatches, lists, tuples, and sets.
* **Functional Modularity:** Pure functions, return values, scope management, and recursion awareness.
* **Object-Oriented Programming (OOP):** Class design, encapsulation, state preservation, and attribute/method modularity.
* **GUI & Graphics (Turtle):** Coordinate systems, stateful drawing, random walks, algorithmic geometry, and color extraction.
* **Clean Code:** Consistent `snake_case` naming conventions, strict PEP 8 formatting, and edge-case handling.
